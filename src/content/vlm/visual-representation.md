## 核心问题

模型知道“这是指针”，为何仍可能把它朝向说错？物体语义可辨认与精确几何关系可辨认，是不同的表征要求。

## 心智模型

原图是高维信号；进入 LLM 的是经过缩放、编码、选择和投影后的表征。表征不是原图副本。对某任务有用的信息可能保留，对另一任务必需的细节可能被压缩、混淆，或虽存在却未被读取。

## 关键概念

- **Pixel information**：颜色与位置的原始采样；裁剪、缩放和压缩都可能改变它。
- **Local / global feature**：局部区域的纹理、边缘与全图语义；两者可能在不同层、不同 token 中呈现。
- **Semantic feature**：支持“这是什么”的表征；**geometric / spatial feature** 支持朝向、位置、距离和拓扑关系。
- **Positional information**：区域在图中的坐标或顺序；如果经过池化、重排或过度压缩，需要检查空间对应是否保留。
- **Information bottleneck**：有限视觉 token 和上下文预算迫使模型压缩输入；“哪些信息丢失”取决于任务和编码方式。

## 它怎样工作

`原始图像 → patch/切片 → encoder hidden states → connector 输出 → LLM hidden states → 答案`。每一步都可问两个不同问题：**信息可解码吗**，以及**生成答案是否因它而改变**。前者可用 probing、线性读出或特征可视化；后者需要遮挡、反事实替换、激活干预等因果对照。

## 为什么重要

分类准确率高通常证明语义判别有效，不直接证明方向、坐标或拓扑精度。反过来，单次方向错误也不能证明编码器没有方向信息，错误可能出在指代、参照系或语言映射。

## 容易混淆

**Representation ≠ usage ≠ explanation**：有信息、用了信息、文字解释忠实地描述用过的信息，是三种不同命题。注意力权重和可读推理链可以提供线索，不能单独当作因果证据。见[感知与推理](../perception-reasoning/)及[失败模式](../failure-modes/)。

## 研究视角

为“小目标朝向”建立两组配对图：类别和背景相同，只改变尖端方向；再比较高低分辨率、不同裁剪与无图对照。若性能仅随有效像素增加而改善，支持输入带宽是瓶颈之一；仍需排除提示和评分影响。

## 代表性工作

[MM1](https://arxiv.org/abs/2403.09611) 对分辨率与视觉 token 做消融；[Cambrian-1](https://arxiv.org/abs/2406.16860) 比较视觉编码器并关注 grounding。这些工作说明不能把“视觉编码器”当作不可分的黑盒。
