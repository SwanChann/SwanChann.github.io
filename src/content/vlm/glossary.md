## 使用方式

这里记录本模块的**工作定义**。社区用法可能不统一；阅读论文时以作者明确给出的操作定义为准。名称相近不代表功能相同。

## 模型与架构

| 术语 | 简明定义 |
|---|---|
| Vision model | 以视觉输入为核心的模型，输出可为类别、框、区域或特征。 |
| VLM | 视觉与语言模型的宽泛社区称呼，包含表征式与生成式路线。 |
| MLLM | 常指以大语言模型为核心的多模态生成模型；边界不完全统一。 |
| Vision encoder | 将图像像素编码为可计算的视觉特征。 |
| Patch | 将图像划分的局部块；ViT 常把它投影成向量。 |
| Visual token | 代表图像区域或聚合视觉信息的连续向量位置。 |
| Projector / connector | 将视觉特征映射、选择或压缩成语言主干可接收的形式。 |
| Q-Former | 以可学习查询抽取视觉信息的连接模块，见 BLIP-2。 |
| Resampler | 将大量视觉特征压缩或重采样为较少表示的模块。 |
| Fusion | 图像与文字信息在模型中结合的机制。 |
| Native multimodal | 作者用来描述较统一的多模态建模设计；不是统一认证标准。 |
| Unified multimodal | 理解与生成等多种模态任务由较统一模型处理的方向；需看具体实现。 |

## 能力与错误

| 术语 | 简明定义 |
|---|---|
| Perception | 从视觉输入提取任务相关对象、属性与关系的能力总称。 |
| Reasoning | 在已获得或生成的事实之上组合、推断或计算；在 VLM 中与感知不一定可完全切分。 |
| Grounding / referring | 将文字表达绑定到图像中的具体实体或区域。 |
| Localization | 输出目标位置，如框、点或区域。 |
| Spatial reasoning | 使用位置、方向、视角、深度等空间信息推断。 |
| Hallucination | 输出无依据或与输入冲突的内容；视觉幻觉指错误声称图中事实。 |
| Visual neglect | 回答对图像证据不敏感或几乎不依赖它的现象。 |
| Bias | 在定义好的数据分布上，错误向某类别或方向系统倾斜。 |
| Calibration | 预测置信度与实际正确率是否对应；自信措辞不是校准概率。 |
| Capability profile | 按能力类别展示模型表现的多维轮廓。 |
| Equivariance | 输入按变换 T 改变时，输出按相应规则变换，如图像方向标签随镜像改变。 |
| Invariance | 输入发生与任务无关的改变时，输出保持不变。 |

## 训练与推理

| 术语 | 简明定义 |
|---|---|
| Pretraining | 用较大规模数据和预设目标学习基础表征或生成能力。 |
| Alignment | 可能指图文表征对齐，也可能指人类偏好对齐；依上下文确定。 |
| Instruction tuning / SFT | 用带指令和目标答案的样本做监督微调。 |
| Post-training | 基础预训练后为特定行为或能力继续训练的总称。 |
| RLHF / DPO / RL | 不同的偏好或奖励式优化路线；具体目标与反馈不同。 |
| CoT | 模型生成的分步推理文本；不能自动视为忠实内部过程。 |
| Test-time scaling | 推理时增加采样、推理步骤或工具预算。 |
| Training-free | 当前方法不更新目标模型权重，不等于没有外部模型或计算开销。 |

## 测量与研究

| 术语 | 简明定义 |
|---|---|
| Benchmark | 由任务、题目、标注、协议和指标组成的测量系统。 |
| Probe | 从内部表征读出某种信息的分析器；可读出不等于被模型使用。 |
| Ablation | 删除或替换因素，测试其对结果的影响。 |
| LLM-as-a-Judge | 用语言模型根据规则评判开放答案；需评估偏差和一致性。 |
| Scaling | 规模、数据或计算变化与表现变化之间的关系。 |
| Emergence | 随规模变化出现的行为描述；需警惕指标阈值与测量效应。 |
| Agent | 能根据观察作决策、调用工具或行动并利用反馈的系统。 |
| VLA | Vision-Language-Action 模型，将视觉与语言输入连接到行动输出。 |
