## 使用方式

这里记录本模块的**工作定义**。社区用法可能不统一；阅读论文时以作者明确给出的操作定义为准。名称相近不代表功能相同。

## 第一次遇到这些词，按什么顺序理解

先理解 **pixel、feature、vector**：像素是图片输入的颜色数值；特征是模型计算结果；向量是一组有顺序的数值，用来表达特征。接着才读 encoder、visual token 与 connector：分别是计算视觉特征的模块、特征序列中的位置、以及让后续模型接收视觉信息的连接部分。

例如猫图经过编码器得到196个向量，每个768维；连接器把每个映射到4096维。196指位置数量，768/4096指每位置数值数量，不能把“更多维”直接解释成“更多物体”。数字是假设教学尺寸，完整过程见[架构](../architecture/)。

再分清 **parameter 与 activation**：权重是控制计算、经过训练保存的数值；激活是当前输入计算出的临时结果。冻结权重不会让所有猫图输出相同特征。**loss** 衡量预测与训练目标的差异，**gradient** 为参数调整提供敏感度信号，见[训练](../training/)。

下面的表格用来回查，每行都给实例和完整解释入口。若短定义仍不够，直接沿入口阅读步骤，而不是用另一个缩写代替理解。

## 模型与架构

| 术语 | 含义 | 具体例子与展开入口 |
|---|---|---|
| Vision model | 以视觉输入为核心的模型，输出可为类别、框、区域或特征。 | 猫图输入，输出类别或猫框。见[基础](../foundations/)。 |
| VLM | 视觉与语言模型的宽泛社区称呼，包含表征式与生成式路线。 | CLIP 匹配“猫图—猫描述”；生成模型回答颜色。见[基础](../foundations/)。 |
| MLLM | 常指以大语言模型为核心的多模态生成模型；边界不完全统一。 | 视觉特征与问题进入语言生成系统。见[架构](../architecture/)。 |
| Vision encoder | 将图像像素编码为可计算的视觉特征。 | 从猫图像素算出向量，不直接返回物体文字清单。见[架构](../architecture/#vision-encoder)。 |
| Patch | 将图像划分的局部块；ViT 常把它投影成向量。 | 16×16 像素的网格块，可能同时含猫和背景。见[架构](../architecture/#vision-encoder)。 |
| Visual token | 代表图像区域或聚合视觉信息的连续向量位置。 | 一个视觉向量位置；196 个位置与每位置768维不是一回事。见[架构](../architecture/#visual-token)。 |
| Projector / connector | 将视觉特征映射、选择或压缩成语言主干可接收的形式。 | 将每位置768个数转换成语言模型所用维度；并非先翻译成中文。见[架构](../architecture/#connector-and-fusion)。 |
| Q-Former | 以可学习查询抽取视觉信息的连接模块，见 BLIP-2。 | 学到的查询从一组视觉特征获取信息，不等于用户问题。见[架构](../architecture/#connector-and-fusion)。 |
| Resampler | 将大量视觉特征压缩或重采样为较少表示的模块。 | 把较长特征序列整理为另一组表示，具体数量与信息保留看设计。见[架构](../architecture/#connector-and-fusion)。 |
| Fusion | 图像与文字信息在模型中结合的机制。 | 让“项圈颜色”的问题与图像特征共同影响输出。见[架构](../architecture/)。 |
| Native multimodal | 作者用来描述较统一的多模态建模设计；不是统一认证标准。 | 看作者实际训练与模块，而不是从名称猜内部结构。见[前沿](../frontiers/)。 |
| Unified multimodal | 理解与生成等多种模态任务由较统一模型处理的方向；需看具体实现。 | 同系统看猫图和生成猫图，可仍有不同视觉路径。见[前沿](../frontiers/)。 |

## 能力词为什么不能互换

认出“猫”是 recognition；找到猫框是 localization；将“戴红项圈的猫”对应到某一框是 grounding。这三项可以分别正确或错误。读到标牌字符是 OCR，知道这些字属于哪个按钮还需要位置与结构。

“感知与推理”按任务可验证事实区分，不要求模型内部独立运行两个模块。把正确坐标给模型后仍算错方向，支持后续比较/映射有问题；不能用一次实验给所有错误定原因。见[感知与推理](../perception-reasoning/)。

## 能力与错误

| 术语 | 含义 | 具体例子与展开入口 |
|---|---|---|
| Perception | 从视觉输入提取任务相关对象、属性与关系的能力总称。 | 找到箭头、读出端点等任务相关事实。见[感知与推理](../perception-reasoning/)。 |
| Reasoning | 在已获得或生成的事实之上组合、推断或计算；在 VLM 中与感知不一定可完全切分。 | 给正确端点后，比较坐标并判方向；在VLM里可能与读图交织。见[感知与推理](../perception-reasoning/)。 |
| Grounding / referring | 将文字表达绑定到图像中的具体实体或区域。 | “左侧红项圈猫”究竟指两只猫中的哪只。见[文字与定位](../text-grounding/)。 |
| Localization | 输出目标位置，如框、点或区域。 | 猫框 `(10,20,70,80)` 必须说明坐标格式。见[文字与定位](../text-grounding/)。 |
| Spatial reasoning | 使用位置、方向、视角、深度等空间信息推断。 | 判断猫在球左边，需要明确比较对象和参照系。见[空间与三维](../spatial-3d/)。 |
| Hallucination | 输出无依据或与输入冲突的内容；视觉幻觉指错误声称图中事实。 | 图中无蓝球却描述有蓝球；该标签尚未解释内部原因。见[失败模式](../failure-modes/)。 |
| Visual neglect | 回答对图像证据不敏感或几乎不依赖它的现象。 | 改变决定答案的图中事实，却未见预期应答变化。见[失败模式](../failure-modes/)。 |
| Bias | 在定义好的数据分布上，错误向某类别或方向系统倾斜。 | 平衡方向后仍出现左右非对称错误，需要跨来源复验。见[失败模式](../failure-modes/)。 |
| Calibration | 预测置信度与实际正确率是否对应；自信措辞不是校准概率。 | 自报90%的那批题是否接近90%正确；不能由措辞判。见[失败模式](../failure-modes/)。 |
| Capability profile | 按能力类别展示模型表现的多维轮廓。 | 将OCR、识别、方向等分别报告，不只用总分。见[能力地图](../capabilities/)。 |
| Equivariance | 输入按变换 T 改变时，输出按相应规则变换，如图像方向标签随镜像改变。 | 右下箭头镜像后方向应换成左下；输出变换另行定义。见[空间与三维](../spatial-3d/)。 |
| Invariance | 输入发生与任务无关的改变时，输出保持不变。 | 翻转猫图，类别仍应是猫；是否不变取决于任务。见[空间与三维](../spatial-3d/)。 |

## 训练与推理

| 术语 | 含义 | 具体例子与展开入口 |
|---|---|---|
| Pretraining | 用较大规模数据和预设目标学习基础表征或生成能力。 | 通过大量分类、配对或其他目标学习可复用特征。见[训练](../training/)。 |
| Alignment | 可能指图文表征对齐，也可能指人类偏好对齐；依上下文确定。 | 图文配对与人类偏好是两种不同含义，查目标再判断。见[训练](../training/)。 |
| Instruction tuning / SFT | 用带指令和目标答案的样本做监督微调。 | 猫图＋颜色问题＋目标答案“红色”构成监督样本。见[训练](../training/)。 |
| Post-training | 基础预训练后为特定行为或能力继续训练的总称。 | 已有基础模型上继续做SFT、偏好等学习。见[训练](../training/)。 |
| RLHF / DPO / RL | 不同的偏好或奖励式优化路线；具体目标与反馈不同。 | 偏好对、奖励模型、任务奖励提供不同反馈；算法并不相同。见[训练](../training/)。 |
| CoT | 模型生成的分步推理文本；不能自动视为忠实内部过程。 | 模型写出“找目标、看颜色”的文字，不是隐藏执行日志。见[感知与推理](../perception-reasoning/)。 |
| Test-time scaling | 推理时增加采样、推理步骤或工具预算。 | 一次改五次采样或多次工具读取，还应记录成本。见[推理时干预](../inference/)。 |
| Training-free | 当前方法不更新目标模型权重，不等于没有外部模型或计算开销。 | 本方法不更新目标权重，可仍调用已训练OCR。见[推理时干预](../inference/)。 |

## 测量词怎样与一次实验对应

一份 dataset 是样本，benchmark 还要包括任务和评分协议。10题答对8题给出 accuracy=80%；找目标时 precision 检查报告的是否正确，recall 检查真实目标漏掉多少。IoU 检查位置区域的重叠比例；这些指标详见[评测](../evaluation/)。

读研究时再分开 observation、hypothesis 与 mechanism：观察是记录错答；假设是预测原因；机制主张需要更强的过程证据。Ablation 删除或替换因素，probe 则读出中间信息；读出成功不等于生成时利用了它。

## 测量与研究

| 术语 | 含义 | 具体例子与展开入口 |
|---|---|---|
| Benchmark | 由任务、题目、标注、协议和指标组成的测量系统。 | 方向题、标签、提示、解析与指标共同组成测量。见[评测](../evaluation/)。 |
| Probe | 从内部表征读出某种信息的分析器；可读出不等于被模型使用。 | 用小分类器从固定编码特征预测红蓝，在新图上验证。见[视觉表征](../visual-representation/)。 |
| Ablation | 删除或替换因素，测试其对结果的影响。 | 比较真工具、空结果和无工具，检查不同因素。见[论文阅读](../paper-reading/)。 |
| LLM-as-a-Judge | 用语言模型根据规则评判开放答案；需评估偏差和一致性。 | 给参考事实和回答，让另一个模型按规则评分；需人工抽检。见[评测](../evaluation/)。 |
| Scaling | 规模、数据或计算变化与表现变化之间的关系。 | 改变参数、数据或计算，看哪项能力怎样变化。见[研究范式](../research-paradigms/)。 |
| Emergence | 随规模变化出现的行为描述；需警惕指标阈值与测量效应。 | 指标越过阈值可制造突跃，要查连续表现和评测设计。见[研究范式](../research-paradigms/)。 |
| Agent | 能根据观察作决策、调用工具或行动并利用反馈的系统。 | 看屏幕、点击、再读反馈决定下一步。见[前沿](../frontiers/)。 |
| VLA | Vision-Language-Action 模型，将视觉与语言输入连接到行动输出。 | 视觉和“移动碗”的语言目标输入，输出机器人动作。见[前沿](../frontiers/)。 |

## 学完怎样使用术语

自检：看到“视觉token”应能说出它来自什么、包含什么形式的数值；看到“training-free”应能指出哪些权重没有更新；看到“bias”应能问出样本分布是否平衡。能做这些具体判断，再使用术语。
