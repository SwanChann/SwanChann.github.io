## 核心问题

“模型反复把右说成左”与“模型每次答案都不同”是不同问题。前者可能是系统偏差，后者是稳定性不足；两者都不能靠几个醒目案例确认。

## 心智模型

同一根右下箭头，模型 A 五次都回答左下，模型 B 有时右下、有时左下。A 更一致，但在这个样本上仍然错；B 更摇摆，也不能因此说它视觉能力更低。先分别记录**正确性、重复一致性、错误分布**，再解释原因。以下重复次数和比例均为教学演示。

## 几种错误怎样在具体任务里出现

### 幻觉与视觉忽略

猫图里没有蓝球，模型却说“猫旁边有蓝球”，这是错误声称视觉事实的一种**视觉幻觉**。它可以来自视觉误认，也可能来自场景常识补全。幻觉描述的是错误输出，不是已经找出的内部原因。

把猫图换成狗图仍回答猫，或不传图片也得到类似答案，可能提示**视觉忽略**：当前回答对图像不够敏感。但一组题有许多固定答案，或换图没有改变被问事实时，“答案不变”未必异常。要改变决定答案的内容，再检查。

### 语义先验与细粒度错误

模型知道“猫常戴项圈”，不代表知道这张图的项圈颜色。若许多训练描述写红项圈，它可能倾向于红色。将同一对象的关键属性改成蓝色、保持其余内容尽量一致，可以检查这个候选解释，不能预先假定它必然存在。

小字读错、小目标漏掉与两个相似物体绑定错，分别可能涉及有效像素、细节区分和 grounding。先标出目标与错误内容，再按[感知与推理](../perception-reasoning/)排查，比把它们全部叫“幻觉”更有用。

### 提示敏感与重复摇摆

在同一图上把“方向是什么”改成“尖端指向哪边”，答案发生变化，称为一种提示敏感现象。等义问题仍可能对模型产生不同输入模式。交换选择题顺序还能检查它是否偏向选项位置。

同一提示多次运行得到不同答案，可能由采样随机性、模型服务版本或实际执行差异影响。必须固定并记录版本、采样参数和输入后再测。降低温度可能减少摇摆，但不会保证答案正确；零温度也不是跨平台、跨时间结果绝对相同的承诺。

## 什么叫系统性偏差

用一个虚构数据集演示：20 道真值为右的题，有 8 道答左；20 道真值为左的题，有 2 道答右。两个方向的错误比例分别是 `8/20=40%` 和 `2/20=10%`。这比只说“方向总准确率75%”多告诉我们一个信息：错误可能向左倾斜。

它仍然可能来自右侧样本更模糊、某种对象只出现在右向题，或评分器总把模糊输出解析成左。需要平衡样本难度、对象和问法，再在新来源上复验，才能支持更广的偏差主张。

**置信区间**表示在给定统计假设下估计值的不确定范围。20 题的比例会有较大抽样不确定性；同一题跑20次也不等于20个独立图像。两种不确定性都应记录，不能把更多重复次数当更多场景覆盖。

## 自信、稳定、校准为什么是三件事

回答“我非常确定”是措辞；五次同答是重复一致；与真值相符才是准确。三者不必同时成立。

**校准**检查数值置信度是否对应实际正确率。教学中，一批题都报90%置信度却只对60%，说明这些自报数字在该设置中不可靠；不能把单题“90%”自动当作90%的正确机会。也要区分模型自报置信度和内部 token 概率，它们并非同一个量。

## 关键概念

| 失败模式 | 可观察表现 | 首要对照 |
|---|---|---|
| Visual hallucination | 声称图中有不存在的对象或属性 | 有图/无图及反事实图 |
| Visual neglect / shortcut | 换图后答案不变，或题干足以猜中 | 无图、无关图、题干改写 |
| Semantic prior dominance | 反常识图按常见情形回答 | 只改图中关键属性的配对样本 |
| Spatial / orientation | 左右、朝向、深度或相对位置错 | 明确坐标系的翻转/旋转配对 |
| Fine-grained / small object / OCR | 小目标、细字、微小差异错 | 分辨率、局部裁剪与人工可读性 |
| Grounding | 选错相似对象或区域 | 指代消歧和定位输出 |
| Prompt sensitivity | 无关措辞改变答案 | 等义提示、选项顺序 |
| Instability | 同条件重复输出摇摆 | 固定版本与采样参数后多次运行 |
| Stable-but-wrong | 多次稳定地给同一错误答案 | 不同图、不同场景的系统复验 |

## 它怎样工作

对左右任务分别记录 `P(预测左 | 真值右)` 与 `P(预测右 | 真值左)`，同时报告样本数、置信区间、提示和输出解析规则。两项不对称只能描述数据集上的错误方向；要称为模型特有偏差，还需平衡图像类型、方向基率和问法，并跨来源复验。

## 为什么重要

错误剖面比一个总分更能指导诊断，也更能检验干预是否只修复某类题。对于 confidence（置信度），要区分语言上说“确定”、模型给出的数值和经过正确率检验的校准概率。

## 容易混淆

高重复一致性不是高准确率；稳定错误也可能来自标注错误、固定答案模板或解析器。视觉幻觉与语言幻觉边界取决于答案是否声称了图中不存在的内容。见[感知与推理](../perception-reasoning/)。

## 研究视角

预先注册方向映射、排除规则和主要指标；用真实与合成两类图像、多个对象类型和多种问法测试。若只在一类图形成立，结论应限定在那类图形。

## 代表性工作

[VLind-Bench](https://arxiv.org/abs/2406.08702) 测语言先验；[MIRAGE](https://arxiv.org/abs/2603.21687) 检验无图答题；[PerceptionBench](https://arxiv.org/abs/2607.24957) 按原子感知能力报告剖面。论文中的数值属于其评测设置，不能直接推断任意模型的稳定偏差。

## 关联与判断

自检：五次一致答错，证明稳定偏差了吗？只证明该样本该设置下重复一致且错，还缺多样样本。左右错误比例不同，能否直接称模型天生偏左？不能，先排除数据和评分不对称。
