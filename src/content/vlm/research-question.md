## 核心问题

观察到“模型把 A 看成 B”之后，何时能说发现了规律，何时只是有趣个案？先让问题有操作定义和反证条件，再讨论修复。

## 心智模型

`Anecdote → 可复现现象 → 跨条件 pattern → 明确的偏差或边界 → 假设 → 控制实验 → research question → 可选干预`。各级别是证据强度，不是必须按名字写论文。

## 关键概念

| 词 | 必须能回答 |
|---|---|
| Anecdote（个案） | 哪个具体样本、模型版本与原始输出？ |
| Phenomenon（现象） | 同条件重跑是否仍出现？ |
| Pattern（模式） | 换图、问法和来源后是否依然存在？ |
| Bias（系统偏差） | 方向或类别的错误分布是否非对称，且排除了基率？ |
| Hypothesis（假设） | 若原因是 X，什么新实验应出现 Y？ |
| Mechanism（机制） | 哪个过程的干预会改变错误，而其他解释不能？ |
| Research question | 什么条件下、哪类模型、哪种能力、哪个可测结果？ |
| Contribution | 新测量、新规律、机制证据，还是改进方法？ |

## 它怎样工作

以“右下指针被说成左下”为通用案例。先确认原图、真值与指针定义；收集多样对象的方向配对；固定 prompt、采样和评分；测 `右→左` 与 `左→右` 的混淆；比较无图、裁剪、翻转以及正确端点提示。若只在一张图成立，结论停在个案。若跨来源稳定非对称，才可提出“某类模型在某类方向任务存在偏差”的限定问题。

## 为什么重要

一个有研究价值的问题通常揭示旧评测遗漏了什么、某种看似有效方法为何无效、或一个能力随条件怎样变化。工程优化也有价值，但“涨分”本身未说明模型学到了什么规律。

## 容易混淆

“我能设计训练免参纠错”是方法想法，不是现象证明。先通过独立数据集验证方向特征与变换映射；对问题的误诊会让后续修复只适配少量示例。自己的观察应放在[独立研究记录](../my-research/)，不写回通用知识页。

## 研究视角

写一个可证伪句式：**在模型组 M、图像条件 C 下，输入变换 T 导致的答案变化显著低于预期等变性；如果更换图像来源、坐标问法或评分规则后效应消失，则原假设需收窄或放弃。**

## 代表性工作

[MMVP](https://arxiv.org/abs/2401.06209) 从视觉表征易混淆的图像对出发，构造测量并分析模型关联；[VLind-Bench](https://arxiv.org/abs/2406.08702) 用条件控制减少反常识题的混杂。这两种提问方式比“再刷一个总分”更接近规律研究。

## 关联与判断

把新问题交给[评测](../evaluation/)确定指标，再用[论文阅读模板](../paper-reading/)反向检查最强替代解释。读完应能为任何一条模型错误写出“验证、反证、边界”三项。
