## 核心问题

观察到“模型把 A 看成 B”之后，何时能说发现了规律，何时只是有趣个案？先让问题有操作定义和反证条件，再讨论修复。

## 心智模型

先写“在这一张图、这一版模型、这个提示下，右下箭头被回答为左下”。这句话比“VLM 不会空间推理”小，但可核查。研究问题的形成，是逐步扩大可验证范围并缩小原因解释，而不是把个案写成一个更大的口号。下面是通用教学案例，不是已完成的个人实验。

## 一步步把观察变成能回答的问题

### 第一步：让个案有可复查的内容

保留原图、模型精确版本、问题、采样设置和原始响应。人工检查箭头尖端与坐标系。如果原图和完整输出都没有，只能说这是转述中的待核实观察。

重复同设置可以检验是否容易再现，但同图跑多次无法说明跨图规律。第一次的任务是证明自己讨论的现象确实存在于具体条件下。

### 第二步：改变样本，寻找成立边界

加入左下、右上、左上箭头，平衡数量；换对象形状、背景、目标大小与问法。看错误是普遍增多，还是只集中在某种方向或某种图。

**Pattern（模式）**是跨条件反复出现的关系；**bias（偏差）**需要更具体的非对称分布。如果右向题本来更难，不能把更多右→左错误全归给模型偏向左。

### 第三步：分清描述性问题与原因问题

“哪些条件下右→左错误更多”是描述性问题，可以先用分组评测回答。“是不是缩放导致尖端看不清”是原因假设，需要改变有效细节并控制其他因素。

把假设写成预测：如果有效分辨率是重要瓶颈，那么改善局部可读性应主要帮助小目标题；如果问题是左右词映射，即使给正确坐标仍可能答反。实际干预会同时改变因素，要配套对照。

### 第四步：给问题加上可测范围

一个候选研究问题可以是：“在指定模型版本与清晰图像坐标任务中，方向错误是否具有跨对象和跨来源的左右不对称，这种差异在匹配有效分辨率后是否仍存在？”

它写出了模型、任务、结果和条件。比“VLM 到底看没看见”更容易回答，因为后者没有规定什么行为算看见。

### 第五步：写下什么证据会让你改主意

如果换评分解析器后非对称消失，可能是评测问题；如果只在一类图形存在，就收窄到该类；如果换数据来源消失，就不能说普遍。**可证伪**不是必须用一项实验推翻所有猜想，而是主张有可能被证据否定或限制。

先定义主要指标和排除规则，再用独立测试样本验证，减少在同一题集不断试到满意结果的风险。探索阶段允许广泛看现象，验证阶段要保留独立证据。

## 工程优化怎样成为研究贡献

“把局部图放大后正确率更高”可能已经满足实际工程需求。它若进一步解释何种目标尺度受益、为何整图放大不等效、在哪些模型和场景失效，就新增了可迁移认识。

新方法同样可能是研究贡献，取决于问题重要性、已有方法不足、方法的新意、可靠证据和泛化，而不是机械要求每篇都有机制解释。反过来，仅换提示并报告精挑样例上的涨分，很难支持宽泛能力主张。

也不是所有尚未被研究的问题都值得做：要检查结果能否改变现有理解、测量或实际决策，实验是否可行，已有文献是否已覆盖相同范围。这里先建立判断方式，不自动认定某个候选方向有新颖性。

## 一个可复用的最小问题卡

| 项目 | 箭头案例怎样填 |
|---|---|
| 观察 | 指定输入下的一次方向错答，附原始记录 |
| 范围 | 清晰尖端、图像坐标、指定模型版本 |
| 待回答 | 是否存在左右不对称，受哪些条件影响 |
| 原因假设 | 输入细节、目标绑定、关系判断或输出映射 |
| 主要对照 | 平衡样本、无图、局部图、正确端点事实 |
| 反证或边界 | 换来源、问法或解析后效应是否消失 |
| 潜在贡献 | 新测量、有限范围规律或受控干预证据 |

## 关键概念

| 词 | 必须能回答 |
|---|---|
| Anecdote（个案） | 哪个具体样本、模型版本与原始输出？ |
| Phenomenon（现象） | 同条件重跑是否仍出现？ |
| Pattern（模式） | 换图、问法和来源后是否依然存在？ |
| Bias（系统偏差） | 方向或类别的错误分布是否非对称，且排除了基率？ |
| Hypothesis（假设） | 若原因是 X，什么新实验应出现 Y？ |
| Mechanism（机制） | 哪个过程的干预会改变错误，而其他解释不能？ |
| Research question | 什么条件下、哪类模型、哪种能力、哪个可测结果？ |
| Contribution | 新测量、新规律、机制证据，还是改进方法？ |

## 它怎样工作

以“右下指针被说成左下”为通用案例。先确认原图、真值与指针定义；收集多样对象的方向配对；固定 prompt、采样和评分；测 `右→左` 与 `左→右` 的混淆；比较无图、裁剪、翻转以及正确端点提示。若只在一张图成立，结论停在个案。若跨来源稳定非对称，才可提出“某类模型在某类方向任务存在偏差”的限定问题。

## 为什么重要

一个有研究价值的问题通常揭示旧评测遗漏了什么、某种看似有效方法为何无效、或一个能力随条件怎样变化。工程优化也有价值，但“涨分”本身未说明模型学到了什么规律。

## 容易混淆

“我能设计训练免参纠错”是方法想法，不是现象证明。先通过独立数据集验证方向特征与变换映射；对问题的误诊会让后续修复只适配少量示例。自己的观察应放在[独立研究记录](../my-research/)，不写回通用知识页。

## 研究视角

写一个可证伪句式：**在模型组 M、图像条件 C 下，输入变换 T 导致的答案变化显著低于预期等变性；如果更换图像来源、坐标问法或评分规则后效应消失，则原假设需收窄或放弃。**

## 代表性工作

[MMVP](https://arxiv.org/abs/2401.06209) 从视觉表征易混淆的图像对出发，构造测量并分析模型关联；[VLind-Bench](https://arxiv.org/abs/2406.08702) 用条件控制减少反常识题的混杂。这两种提问方式比“再刷一个总分”更接近规律研究。

## 关联与判断

自检：“我准备加一个纠错模块”是研究问题吗？它首先是方法想法，还需说明为何需要、改善什么、怎样与已有方法比较。“模型偏左”是什么级别主张？比一次错答更强，需要平衡与复验支持。

把新问题交给[评测](../evaluation/)确定指标，再用[论文阅读模板](../paper-reading/)反向检查最强替代解释。读完应能为任何一条模型错误写出“验证、反证、边界”三项。
