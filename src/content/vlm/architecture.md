## 核心问题

“图片进入 LLM”到底经历了什么？对生成式 VLM，可先追踪一条常见路径：像素 → 预处理 → 视觉编码器 → 特征序列 → 连接器 → 多模态融合 → 输出。实际模型可能省略或合并其中的模块。

## 心智模型

把架构想成**带宽受限的证据传递链**。前一步没有保留的信息，后一步很难凭空恢复；后一步能读到的信息，也可能因训练或提示而不被使用。

## 关键概念

### Vision encoder

CNN 输出带空间位置的 feature map；ViT 将图像切成 patch，投影为向量并经多层 attention 形成特征。输出不是物体清单，而是一组高维向量。全局语义、局部纹理和位置可在其中以不同程度编码。可用 probe 检查信息是否可被读出，但 probe 成功不证明生成答案时使用了它。

### Resolution

固定分辨率会缩放图像；高分辨率、tiling（切片）、crop（裁剪）、multi-scale（多尺度）和动态分辨率尝试保留小目标与文字。它们改变视觉 token 数量、计算量及局部与全局信息的权衡。放大一块区域若原图已把细节压没，可能需要重新从原始像素编码，而非仅放大已有低分辨率特征。

### Visual token

通常指代表图像区域或压缩结果的连续向量。text token 对应离散词表中的符号，visual token 对应视觉特征位置；两者可在模型隐藏维度中对齐，但语义和来源不同。token 数越少，计算越省，局部信息的压缩压力通常越大。

### Connector and fusion

线性投影、MLP、Q-Former、resampler 或 Perceiver 式模块可映射、选择、汇聚视觉特征。融合可以是视觉 token 与文本 token 拼接、跨注意力、交错图文序列，或更统一的 Transformer。设计差异改变何时、何处、以多少 token 提供视觉信息；不能仅凭模块名称推断模型一定利用了图像。

## 它怎样工作

以回答“右下角按钮写了什么”为例：预处理需保留角落；编码器需提取字形；连接器需传递相关区域；LLM 需把问题定位到该区域，识别文字并输出。任何环节失败都会导致最终答案错误。对于只有 API 的闭源模型，内部链条通常无法逐层确认，只能做输入输出干预。

## 为什么重要

架构决定**可能获取**什么证据，训练决定**倾向使用**什么证据，评测决定我们**看见了哪类结果**。混淆这三层会把系统差异错归因于视觉编码器。

## 容易混淆

“更大 LLM”可能改善知识与语言组合，但不保证小字可读。MM1 在其消融条件下报告分辨率和视觉 token 数影响显著，连接器类型影响相对小；Cambrian-1 则系统比较多个视觉编码器。两者的结论都带条件，不能变成永恒的架构排名。[MM1](https://arxiv.org/abs/2403.09611) · [Cambrian-1](https://arxiv.org/abs/2406.16860)

## 研究视角

研究组件作用时固定底座、训练数据、分辨率和 token 预算中的其他变量；报告性能同时报告计算开销。若无法控制所有变量，明确标成跨系统比较。

## 代表性工作

[BLIP-2](https://arxiv.org/abs/2301.12597) 的 Q-Former、[LLaVA](https://arxiv.org/abs/2304.08485) 的简单投影、[Qwen2.5-VL](https://arxiv.org/abs/2502.13923) 的动态分辨率设计分别展示连接与输入处理的不同选择。闭源 GPT、Gemini、Claude 的未公开内部细节不在此推断。
