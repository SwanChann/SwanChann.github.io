## 1. DeepSeek 开放完整应用 API

联网搜索、深度思考搜索、文件输入、链接阅读和安全检查进入 V4.1-Flash 的 Messages、Responses、Chat Completions 接口，由服务端完成工具调用和上下文组织。同时提供独立的 Search、Fetch、OCR、ASR、TTS 接口，并开源支持导入历史对话的聊天前端。对开发者来说，可以少写一层检索、解析与语音接入代码，直接搭建更完整的应用。工具费用与模型 token 费用分开计算。[官方公告](https://api-docs.deepseek.com/news/news261113/)

## 2. llama.cpp 与 ggml 正式发布 1.0

这次的重要变化是接口稳定性承诺：公共 API、ABI 的不兼容变化将通过主版本号明确标示，方便下游项目管理升级。版本还加入 FP8 KV cache、主机内存 MoE 专家缓存，扩展模型支持，并修复 llama-server 的 SSRF、CORS 等安全问题。维护本地推理服务的团队值得关注，但升级前应检查被移除的弃用接口。[团队公告](https://huggingface.co/blog/ggml-org/llama-cpp-v1) · [发布说明](https://github.com/ggml-org/llama.cpp/releases/tag/v1.0.0)

## 3. NVIDIA 发布 Isaac Sim + SimReady 抓取搬运实操教程

新教程把 UR17G 机械臂、Robotiq 2F-140 夹爪和饮料罐资产组合进 Isaac Sim 6.2，并演示让 AI agent 辅助装配、检查关节与碰撞、生成控制代码。对仿真开发更有用的是验证流程，而不是演示视频本身。官方明确限定：固定已知位置、没有视觉、沿固定路径运动，不能据此推断真机可靠性或泛化能力。这是新工作流教程，并非 Isaac Sim 新版本。[NVIDIA 原文](https://huggingface.co/blog/nvidia/simready-assets-robot-pick-and-place)

## 4. ChatGPT Wallet 开始推出，补上 agent 的支付环节

用户逐笔核对商品、金额和支付卡，再通过安全验证批准交易；agent 和商家得到支付 token，而非用户真实卡号。首批面向美国年满 18 岁、持符合条件美国发行卡的 ChatGPT Pro 用户，通过 dots 使用。它的实际进展是让获授权的 agent 可以完成支付，不代表 agent 已能不经确认自行消费。[OpenAI 官方公告](https://openai.com/index/introducing-chatgpt-wallet/)

## 5. Codex CLI 0.169.0：多侧聊与项目信任修复

可选终端工作区新增多个侧聊标签、重启后恢复本地侧聊，以及终端内配置自定义模型服务商。更值得开发者注意的是：在未信任目录运行 codex exec 时，即使使用 workspace-write，也不会加载项目配置和 MCP 服务，避免把目录内配置直接当成已授权执行环境。[官方发布说明](https://github.com/openai/codex/releases/tag/rust-v0.169.0)
