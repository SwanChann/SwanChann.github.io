### 具身智能｜小鹏发布图灵物理 AI 架构，IRON 登台演示

11 月 25 日，小鹏在科技日发布图灵物理 AI 架构（VLA 3.0），用同一套分层思路描述汽车与人形机器人的控制：**System 2** 用视觉语言模型和状态机理解目标、规划任务，**System 1** 快速生成可执行动作，**System 0** 管理实时本体控制和硬件反馈。升级版 IRON 在现场做了对话与互动展示。这里的新进展是架构发布和现场演示，不能据此判断机器人脱离演示环境后的任务成功率。[小鹏官方发布](https://www.xpeng.com/pressroom/news/01a212b0d830a1e838d68a02a2110174) · [现场图片与报道](https://www.ithome.com/1/032/159.htm)

同场首发的图灵 AI 共驾，首个功能是在驾驶员松开加速踏板后，按道路情况调节减速与能量回收，小鹏计划 12 月首批 OTA 推送。这不等于把车辆控制权交给大模型。对机器人也一样：看分层架构是否有效，最好同时公开各层接口、时延预算，以及上层判断出错时底层能否安全停止或恢复。[官方功能说明](https://bbs.xiaopeng.com/article/3988725?tidType=1)

### 仿真评测｜AA-Robotics-Sim 预览：Astra 一轮用 24.6 分钟，机器人只动 35 秒

北京时间 11 月 26 日凌晨，Artificial Analysis 发布 AA-Robotics-Sim v0.1 研究预览。在 Isaac Sim 中，九个代理通过同一套 SONIC 全身控制器与手臂规划器操作带头部 RGB-D 相机的 Unitree G1，完成十类任务。GPT-6.2 Astra 得 **71.0 分**（含阶段性部分得分），完整完成 **61/100** 个评测回合。单回合平均耗时 **24.6 分钟**，机器人的运动时间平均 **35 秒**，不计练习。这两项时间的差额不能全部算成纯模型推理，还包括观测、工具调用和代码执行。[评测原文与任务图](https://artificialanalysis.ai/articles/aa-robotics-sim) · [耗时与成本分解](https://artificialanalysis.ai/articles/aa-robotics-sim#time-cost) · [发布帖](https://x.com/ArtificialAnlys/status/2125683694103064979)

代理可把五次练习写下的代码和笔记带入新场景，但正式评测仍调用模型。练习和评测的场景与环境版本不同，也没有在同一批场景中不给练习文件的对照，因此不能据此断言练习文件带来多少提升。更有说服力的下一步是固定场景、观测和控制器，比较**每次都调用模型**与**只运行冻结程序**，分别记开发成本、运行耗时、任务通过率和恢复次数。

### 大模型服务｜千问下线 Qwen4-Max 预览，旧 ID 继续可用但改变路由与计费

北京时间 11 月 25 日 10:00，`qwen4-max-preview` 下线。按千问平台公告，原 ID 不会立即报错，请求会转到正式版 `qwen4-max`，按正式版统计用量和计费，预览期折扣结束。同日，百炼更新记录新增面向分类、是非判断和评分的 `decision-model`，可返回概率分布与置信度。这是两个不同的变化：前者是服务迁移，后者是结构化判断接口，不是 Qwen4-Max 再次首发。[千问平台更新日志](https://platform.qianwenai.com/docs/changelog/models) · [百炼模型上架记录](https://docs.bailian.console.aliyun.com/zh/model-studio/newly-released-models)

旧 ID 还能调用，不代表实验条件没变。长跑评测应把模型 ID、实际版本和日期一起锁进日志；对新决策接口，则应先用留出的样本检查置信度是否可靠，再把它接进自动分流。

### 工程｜Anthropic 公开 Claude API 的 Rust 迁移复盘：测试通过率 98%，线上起初仅约四分之一匹配

Anthropic 11 月 25 日发布工程复盘，披露如何用旧 Python 服务当验证器，在生产流量上比对 Rust 实现，并让 Claude 代理排查差异。公司称，迁移初期 Rust 版本通过约 **98%** 的测试，却只在约 **四分之一** 的线上输入上与旧版匹配；连工具调用 JSON 的字符转义差异都可能改变模型看到的输入。公开流量在 9 月已迁移，这次的新内容是工程过程和测量结果，不是 API 当天才切换。[Anthropic 工程原文与图表](https://www.anthropic.com/research/migrating-api-to-rust)

Anthropic 报告迁移后每请求 CPU 用量约少 **70%**，首 token 延迟中位数约低 **20%**。这是运行指标，不代表 Claude 模型本身提速了同等幅度。对机器人也有类似教训：换仿真器或控制接口时，除了确认脚本能跑，还要用同一批轨迹比对传感输入、动作输出和终态判定，避免把接口差异当成策略退化。
