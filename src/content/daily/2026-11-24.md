### 具身智能｜RoboChallenge Zero 首发：简单抓放能做，解线仍是 0/55

11 月 23 日，RoboChallenge 公布首轮真机评测：11 个多模态模型、两类真机平台、6 项任务、330 次试验，整体完整成功率为 **44.85%**。GPT-6.2 Astra 完成 **21/30** 次，Claude Fable 5.2 完成 **20/30** 次，只差一个试次。按任务看，写出「Z0」只成功 **4/55** 次；解开充电线并按要求铺好是 **0/55**，其中有一次解开但没有铺好。成功的积木放置和玩偶抓取平均仍要约 13–14 分钟。[评测方原文、任务图与结果](https://www.qbitai.com/2026/11/511978.html) · [RoboChallenge 官网](https://robochallenge.ai/)

这比名次更有研究价值：模型根据相机与机器人状态调用工具，下发末端位姿和夹爪指令，不是直接输出电机力矩。测到的是模型、控制接口与执行层组成的系统。做同类实验时，可以把完整成功、阶段进展、失败恢复和总耗时分别报告，避免把「解开了但没铺好」和「完全没进展」混为一谈。

### 具身智能｜自变量发布 WALL-OSS-1.0 技术报告，真机 API 开放申请

自变量机器人于 11 月 23 日发布 WALL-OSS-1.0：以 Qwen3.5 为起点，将语言、视觉语言和离散化的机器人动作放进统一预训练，再由动作专家输出连续动作段。公司报告的开放式真机零样本成功率是 **55.1%**，口径为 377 次评估合并重复指令后得到 312 条不同指令。这是厂商自测，任务、硬件和评分都不同于 RoboChallenge Zero，两个百分数不能直接比较。[技术报告与架构图](https://x2robot.com/en/blog/wall-oss-1) · [公司发布稿](https://www.globenewswire.com/news-release/2026/11/23/3408046/0/en/x-square-robot-introduces-wall-oss-1-0-understand-more-act-better-a-native-foundation-model-for-the-physical-world.html) · [API 接入说明](https://x2robot.com/docs/quantax1pro/v1/model-development/wallx-api/api-usage-instruction)

WALL-API-1.0 目前按申请接入。能调用 API 不等于能拿到完整模型权重；公开的 Lite 预览也不能当作此次完整模型的检查点。[Lite 预览模型卡](https://huggingface.co/x-square-robot/wall-oss-1.0-lite-robodojo-base)

### 机器人研究工具｜LeRobot 的 FastWAM 可选输出预测视频

11 月 23 日，LeRobot 主分支合并新选项：开启后，FastWAM 在返回动作时也能输出各相机的预测帧，默认关闭。合并记录显示，小模型测试中开关前后动作一致；额外的视频去噪和解码会增加计算，提交者未用完整权重验证。它适合把预测帧、实际观测与动作时间戳并排检查，不代表预测视频参与了动作决策，也不是新的模型权重发布。[合并记录与测试说明](https://github.com/huggingface/lerobot/pull/5336)

### 具身智能｜Dreamer 研究者创办 Embo，获 1.1 亿美元种子轮融资

11 月 23 日，Danijar Hafner 和 Wilson Yan 创办的 Embo 走出隐身阶段，获 a16z 领投的 **1.1 亿美元**种子轮融资。团队计划以视频和机器人示范训练世界模型，让策略在模型中练习并学习从失败中恢复。这里的新进展是公司与融资公布，不是可下载模型或已验证的真机成绩。[领投方公告](https://a16z.com/announcement/investing-in-embo/) · [融资报道](https://robotsbeat.com/embo-110m-seed-a16z-nvidia-robot-world-models/)

这一路线最值得追问的不是视频够不够逼真，而是模型能否预测**换一个动作会发生什么**，尤其是打滑、卡住等少见但决定任务成败的接触事件。最终应以同等真机采样量下的恢复成功率验证收益。

### 大模型｜GLM-5.4 首发：把同一段 28 层网络跑两遍

智谱于 11 月 23 日公布 GLM-5.4。它在一次前向计算中重复执行同一段 **28 层**网络并共享权重，增加了有效深度和每个 token 的计算量，但不等于把参数翻倍。发布时先向 Coding Plan 用户开放；普通按量 API 尚待推出，权重也未随公告公开。[智谱公告](https://z.ai/blog/glm-5.4) · [ZCode 接入文档](https://zcode.z.ai/cn/docs/configuration)

对代码代理，检验这类设计是否划算，要看同一仓库任务的通过率、总耗时和每个成功任务的成本，而不只是参数量或单次模型得分。

### 大模型｜GPT-6.2 Sol 开始进入 ChatGPT 常规聊天

北京时间 11 月 24 日凌晨，OpenAI 宣布向 Plus、Pro、Business 和 Enterprise 推出针对常规 Chat 调整的 GPT-6.2 Sol 变体，组织账号受管理员设置约束；**此次不改变 Work 或 Codex**。OpenAI 披露的内部 Chat 图像理解评测是 71.7%，对照 GPT-6 为 47.4%。这是厂商测试，不是独立评测，也不能用来推断两者的代码或机器人控制表现。[ChatGPT 更新日志](https://help.openai.com/en/articles/6825453-chatgpt-release-notes) · [发布通知](https://x.com/ChatGPT/status/2124942186425069836)

### 大模型｜腾讯微信团队正式公布 WePocketModel 1.0 开源

11 月 23 日，团队正式公布 WePM 1.0 开源，提供 **2B、4B** 两档，可下载标准权重及 GGUF 版本。同一个视觉语言骨干支持向量检索、OCR／视觉问答和结构化决策。作者报告，4B 版相较其选出的专用模型组合少用 **61.9% 的常驻权重内存**，但这个数字不是峰值运行内存，也不是所有部署方式的节省幅度。权重仓库和论文早于正式公告出现。[官方仓库](https://github.com/Tencent/WePocketModel#news) · [4B 模型卡](https://huggingface.co/tencent/WePocketModel1.0-4B) · [论文原文](https://arxiv.org/abs/2611.27365)

### 开发工具｜Claude Ship 测试自动修 PR 和按团队规则审批

Anthropic 于 11 月 23 日公布 Claude Ship：在此前已正式可用的 Code Review 之外，新增面向 Team、Enterprise 的 GitHub 测试功能 **PR Steward** 和 **Claude Approvals**。前者处理 CI 失败、合并冲突和评审反馈，但不批准或合并 PR；后者按团队自定义规则做审批，既有分支保护和必需检查仍生效。[Anthropic 产品公告](https://claude.com/resources/articles/introducing-claude-ship)

值得保留的是自动修改与审批的边界：能修复 CI 并不意味着改动符合发布策略。试用时可以先从低风险仓库开始，核对每次自动提交的差异和回退记录。
