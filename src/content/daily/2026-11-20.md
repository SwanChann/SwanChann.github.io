### 机器人仿真｜Steel 0.2 发布，增加闭环关节与磁性接触

Skild AI 宣布 Steel 0.2 提供 81 个仿真环境示例、交互文档和迁移指引，并展示了可吸附、保持和释放的磁性接触，以及适用于夹爪和平联机构的闭环关节。磁性接触当前在 Skild 的集成分支，并非 Newton 1.8.0 的现成功能。团队还介绍了在 Isaac Lab 中把现有 PhysX 或 MuJoCo 环境迁移到 Steel 的路径。这是 Newton 生态里的求解器工具更新，不是 MuJoCo 或 Isaac Lab 本体发版。[Skild AI 发版公告](https://x.com/SkildAI/status/2123480604444684354) · [迁移说明公告](https://x.com/SkildAI/status/2123480605845528668) · [官方版本说明](https://skild-ai.github.io/steel/start/versions/) · [官方代码库](https://github.com/skild-ai/steel)

迁移时建议先用相同初态和动作做一轮跨引擎回放，对比接触触发、持续时间和释放后的轨迹，再比较训练吞吐。场景能加载，不代表原来的成功判据还能直接用。

### 具身智能｜星动纪元公布 M7 现场分拣演示

星动纪元公布了 M7 在 APEC 工商领导人峰会上的现场包裹分拣演示。厂商称，相关方案已用于中国邮政、顺丰等客户的十余个物流中心，供件吞吐超过每小时 1,500 件。这个数字是厂商披露的作业指标，不能当作整班无人工接管的稳定产能；公告未给出对应的人为干预、错分和停机数据。[星动纪元公告](https://www.prnewswire.com/news-releases/robotera-invited-to-apec-ceo-summit-for-second-consecutive-year-showcases-real-world-humanoid-robot-applications-302945294.html)

### 世界模型｜Genie 4 从网页试用扩展到开发者 API

Google 开始通过 Gemini Interactions API 和 Google AI Studio 提供 Genie 4。这次新增的是程序化调用入口，不是重复发布昨天的 Project Genie 订阅试用。官方称，模型能从文字或参考图生成 720p、24 帧/秒的可交互场景，并同步生成音频。[API 发布公告](https://blog.google/innovation-and-ai/technology/developers-tools/genie-4-in-gemini-api/) · [DeepMind 模型卡](https://deepmind.google/models/model-cards/genie-4/)

对机器人研究，适合先用它生成光照、视角和背景的变化，测试感知模型是否稳定；力、关节状态和接触是否成功，仍应由物理仿真或真机测量来判断。

### 大模型工程｜OpenAI 披露 Codex 自动排查性能回退的工作流

OpenAI 公布 Performance Factory 的实际工作方式：性能告警触发 Codex 排查，另一环节质疑诊断，工程师审查修复方案，部署后再由独立智能体确认指标是否回到基线。OpenAI 称，系统在三个多月里跟踪了 1,700 多项调查，定位了 600 多起问题的根因；这不等于自动修复了 600 多起。[OpenAI 工程报告](https://openai.com/index/how-openai-performance-factory-keeps-chatgpt-fast/)

这套分工可以借给机器人训练：提出改动和验收改动分开，后者用同一套冻结的评测、回放和判据重跑，避免一边改奖励一边放宽成功定义。

### 算力政策｜美国先进芯片远程访问规则正式生效

美国商务部工业与安全局（BIS）的临时最终规则于 11 月 19 日正式刊登并生效。规则针对特定先进芯片和数据中心向总部或最终母公司位于指定地区的企业提供远程访问的若干情形，设置出口、再出口及境内转移许可要求，同时正式撤销此前的 AI Diffusion Rule。它不是所有云端模型 API 的一刀切禁令。[美国《联邦公报》原文](https://www.govinfo.gov/content/pkg/FR-2026-11-19/pdf/2026-23529.pdf)
